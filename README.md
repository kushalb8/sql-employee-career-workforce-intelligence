# SQL Employee Career & Workforce Intelligence

A SQL analytics project analyzing employee data to identify **career stagnation, salary disparities, qualification–role mismatches, leave patterns, and workforce risk**.

## 🎯 Objectives

* Identify career stagnation
* Analyze salary disparities
* Detect qualification–role mismatches
* Analyze leave patterns
* Identify employees with high workforce risk
* Support data-driven HR decisions

## 🔍 Key Analysis

* Employees with 5+ years of experience in Junior/Mid-level roles
* Employees earning below their department average
* Departments with the highest salary gaps
* Qualification and role-level mismatches
* Employees with high leave usage
* Employees with the highest risk scores

## 🛠️ SQL Concepts

**JOINs • Subqueries • GROUP BY • CASE • Aggregate Functions • HAVING • ORDER BY • Views**
